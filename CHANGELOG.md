# История изменений

Версия пакета задаётся в `src/config.xml` и поднимается командой `python pack.py --bump`.
Нумерация: **patch** — исправления и небольшие функции, **minor** — заметные новые возможности.

## 1.7.41
- «Настройки → Обновление → **Поддержать проект**»: QR-код на GitHub Sponsors для телефона.
- README: установка с телефона через [TV Installer](https://github.com/sunic007/tvinstaller), шаги по официальной
  инструкции Samsung (Apps → App Settings → 12345).

## 1.7.40
- «Настройки → Обновление» по частям: **Lampa** (версия, откуда загружена, что на сервере byskaz), **плагины Skaz**
  (обновляются сами при запуске), **функции пакета** (версия, с GitHub или из пакета). «Проверить и обновить» —
  всё сразу.
- Переключатели «Обновлять Lampa сама» и «Обновлять с GitHub» больше не связаны между собой.

## 1.7.39

## 1.7 — Telegram-бот, семья и несколько ТВ, автообновление с GitHub

**Telegram-бот**
- Уведомления о новых сериях, «сегодня выходит», «напомнить завтра», сводка на неделю.
- Поиск по названию, году и студии; результаты — слайдером с постером и описанием.
- «▶️ Смотреть» — ТВ сам открывает фильм и запускает плеер; «Открыть на ТВ», «Хочу посмотреть», подписки.
- Поиск по скриншоту и по описанию с ИИ (Groq, Gemini, OpenRouter — по очереди, со своим бесплатным ключом).
- Семья в одном боте: вход по QR в поиске Lampa, у каждого свои списки, подписки и уведомления;
  «Кому подписка?» на ТВ; владелец видит, кто подключён, и может отключить.
- Несколько ТВ: выбор, на каком включить, имена из настроек ТВ, переименование в боте; бот переходит на другой ТВ
  за минуту, ТВ с более новой версией ведёт бота.
- Подключение: QR и страница на GitHub Pages; второй ТВ — кодом из 8 цифр, без токена.
- Записи Shots («Записать» в плеере) приходят в бот видео.

**Просмотр**
- «Смотреть» на карточке — сразу с места; новый фильм — сразу в русской озвучке.
- «Продолжить / Начать сначала», предыдущая и следующая серия, плашка «Сезон · Серия».
- «День» (+10/20/30 %) и «Ночь» (30/50/70 %), кнопка «Сон», своя громкость для каждого фильма, «ночью не громче».
- Кнопка «Подписаться» в плеере на любой серии идущего сериала.
- Запасной плеер для потоков, которые не тянет плеер ТВ; автовыбор плеера.
- Клавиатура Lampa вместо системной; настройки разложены по разделам.

**Пакет**
- Автообновление функций пакета с GitHub (через jsDelivr) с возвратом к встроенной версии при сбое.
- Ряд Smart Hub по умолчанию не обновляется — значок Lampa на главном экране не пропадает.

## 1.6 — надёжность и скорость
- Автоподбор и проверка вариантов просмотра заранее; загрузка не зависает.
- Быстрый старт видео, буфер плеера, качество под скорость интернета, память звуковой дорожки.
- Кнопка «Смотреть» на карточке одним нажатием, раздел турецких сериалов, детский режим.
- Проверка на официальном эмуляторе Samsung TV, автотесты.

## 1.4–1.5 — основа
- Lampa из пакета с автообновлением Lampa и плагинов; запуск без сервера.
- Автовыбор серверов Skaz, сторож плеера, пропуск заставок и титров, главы фильма.
- Плеер Samsung (AVPlay), цветные кнопки пульта, тихие уведомления, понятный запуск.
